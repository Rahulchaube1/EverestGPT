# EverestGPT 🌄

EverestGPT is a fast, lightweight, and fully open-source local AI chatbot, built for performance and privacy. It runs entirely on your device and provides intelligent conversations through a sleek and easy-to-use interface.


---

## 🔧 Features

- 🧠 Fast, local AI chatbot
- 🗣️ Beautiful chat interface using Gradio
- 💾 Small model size, low memory usage
- ⚡ Blazing-fast inference on CPU
- 📦 Portable and deployable on Hugging Face, GitHub, and cloud platforms
- 💬 Great for developers, learners, and AI enthusiasts
